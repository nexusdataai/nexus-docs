# v0.1.0 -- NexusAI Data-AI Platform

First release of the **NexusAI Data-AI Platform** following the rebrand from the legacy CallSense Toolkit. v0.1.0 establishes the three-plane architecture (Data / Control / Reasoning), the Console (AI Analytics + AI Automation), the Solutions catalogue across 7 industry verticals, and Kubernetes-native deployment via the Nexus Capability Operator.

**Status:** GA  
**Deployment:** Kubernetes-native (cloud or on-premise)  
**Supports migration from:** CallSense Toolkit / NexusAI Toolkit Deployer

---

## What's new

### 1. Three-plane AI Operating System

A layered, Ontology-driven architecture organised into three planes plus a Console. See [Platform Architecture](../../platform-architecture.md).

- **Data Plane** -- Virtual Data Layer hydrated via FDW (live), ETL (batch), or CDC (streaming). One query API across every connected enterprise system, no rip-and-replace. Six-tab console (Data Sources, Virtual Data, Entity Explorer, Mapping Rules, Data Pipelines, Connectors). See [Data Plane](../../planes/data-plane.md).
- **Control Plane** -- Ontology bundle + Knowledge Graph (Apache AGE) + vector embedding index (pgvector). Six-tab console for the Knowledge Pipeline, Knowledge Index, Knowledge Graph, Policy Builder, Workflows, and Integration Rules. See [Control Plane](../../planes/control-plane.md).
- **Reasoning Plane** -- ReAct (Reason + Act) agent loop with Intent + Risk Analyzer, registered Tool Registry, and Policy Engine. Four-tab console: AI Copilot, Planning Playground (with Retrieval Quality Score), ReAct Tools, Tool Builder. See [Reasoning Plane](../../planes/reasoning-plane.md).

### 2. Console -- AI Analytics

Lifecycle management for dashboards and views, plus a multi-step **Dashboard Builder** with an **AI Query Builder** that turns natural-language prompts into structured queries against the Virtual Data Layer.

- Three primary tabs: Dashboards, Views, Solution Mapping.
- 20 built-in panel types across 7 categories.
- Four-views framework (Outcomes / Predict / Diagnose / Monitor) auto-seeded for every Solution.
- See [AI Analytics](../../console/ai-analytics.md).

### 3. Console -- AI Automation

The **Journeys** runtime: repeatable, scheduled, multi-step business operations.

- Three primary tabs: Journeys, AI Copilot Journey, Journey Builder.
- Per-journey **Journey Studio** drill-down with KPI tiles, processing-stage list, and per-step Logs (N) trace.
- Journey Templates per pipeline type (Semantic RAG indexing) and per Solution.
- Triggers: Manual, Schedule, Webhook.
- Tool Palette grouped by category (Core, Supply Chain, O2C, Write, ...).
- See [AI Automation](../../console/ai-automation.md).

### 4. Solutions catalogue -- 7 vertical-aligned app catalogues

Each Solution is a vertical-aligned enterprise application that bundles the ontology entities, KPI targets, dashboards, and journeys for one slice of the business. See [Solutions Catalogue](../../console/solutions-catalogue.md).

- [Supply Chain](../../app-catalogue/supply-chain/index.md) -- Demand Forecasting, Inventory Optimisation, Order-to-Cash Monitor, Supply Chain Risk, Customer 360, Procurement Analytics, Production & Quality, ESG.
- [Finance & Banking](../../app-catalogue/finance-banking/index.md) -- Customer 360, Credit Risk & Early Warning, Fraud Detection & AML, Regulatory Compliance, Treasury, Loan Lifecycle, Revenue Optimisation, Operational Risk.
- [Telecommunications](../../app-catalogue/telco/index.md) -- Customer 360 & Churn, Network Performance, Revenue Assurance & Fraud, Customer Experience, Network Capacity, Dynamic Pricing, Field Operations, Regulatory Compliance.
- [Retail](../../app-catalogue/retail/index.md) -- Customer 360 & Loyalty, Demand Forecasting, Personalisation, Price Optimisation, Inventory & Fulfilment, Store Operations, Supplier & Merchandising, Sustainability.
- [Healthcare](../../app-catalogue/healthcare/index.md) -- Patient 360, Clinical Decision Support, Revenue Cycle, Operational Efficiency, Population Health, Supply Chain & Pharmacy, Clinical Quality, Regulatory Compliance.
- [Customer Operations](../../app-catalogue/customer-ops/index.md) -- Autonomous Issue Resolution, Proactive Agent Assist, Unified Operations Hub.
- [Revenue Operations](../../app-catalogue/rev-ops/index.md) -- Deal Intelligence, Pipeline Risk Forecasting, Revenue Orchestration.

Each Solution opens into a dedicated workspace shell with **Analytics** (Business Insights, Process Analytics, Workflow Actions, Reports), **Views** (auto-seeded four-views), and **Workspace** (Agent Builder, Tools Catalogue). The canonical worked example is **Order-to-Cash Monitor** -- see [Solutions Catalogue > Order-to-Cash](../../console/solutions-catalogue.md).

### 5. App-curated Tools Catalogue

The Tools Catalogue inside each Solution app is now **app-aware**: it surfaces only tools relevant to that Solution, grounded in its ontology entities.

For Order-to-Cash, the catalogue ships:

- **Order Match Verifier** (Analysis) -- three-way match across `Opportunity` / `Delivery_Document` / `Oracle_AR_Invoice`.
- **Order Anomaly Scorer** (Analysis) -- cycle-time deviation, missing delivery, missing invoice signals.
- **AR Cash Flow Projector** (Analysis) -- projects cash inflows from open AR invoices.
- **O2C Alert Generator** (Automation) -- evaluates O2C alert rules and emits alerts.
- **Dunning Notice Composer** (Automation) -- aging-bucket-aware dunning notices for overdue invoices.
- **DSO Optimizer** (Enhancement, Coming Soon) -- recommends levers to reduce Days Sales Outstanding.

Other Solutions ship their own curated tool sets; the platform provides an honest empty state where curation has not yet been authored.

### 6. Kubernetes-native deployment

The **Nexus Capability Operator** reconciles `NexusCapability` custom resources on any EKS or compatible cluster. Single CRD provisions AWS data services (DynamoDB, S3, Glue), creates SSM parameters and Secrets Manager secrets, sets up IAM roles via IRSA, deploys frontend and backend containers, and creates an ALB Ingress with path-based routing. See [Operations > Kubernetes Operator](../../operational/kubernetes-operator/index.md).

### 7. Identity and governance

- Cognito SSO with PKCE OAuth flow; session cookies for browser, bearer tokens for service-to-service.
- Role-based access enforced at every Plane and every Solution app.
- Policy Engine (OPA-compatible) gates every write action with approval thresholds, close-window restrictions, field-level access, cross-system checks, dry-run mode, and max-step limits.
- Per-step audit trail (intent, retrieved context, tool call, result, policy violation) recorded in DynamoDB `control-plane-audit`.
- SOC 2 Type II posture; GDPR + CCPA support; data stays in customer infrastructure.

### 8. Documentation overhaul

The documentation site has been rebuilt around the new architecture: dedicated drill-down pages per Plane and per Console surface, the canonical Order-to-Cash Solution-app worked example, an end-to-end functional + non-functional Business Requirements catalogue, and per-Solution catalogues for all 7 verticals. See [Platform Architecture](../../platform-architecture.md) as the entry point.

## What's removed (vs CallSense Toolkit)

The following surfaces from the legacy CallSense / NexusAI Toolkit Deployer product are retired in this release. See the [Migration from CallSense Toolkit](../../migration/from-callsense-toolkit.md) for where each retired surface now lives.

- **NexusAI Toolkit Deployer User Guide** (11-page wizard-driven AWS deployment) -- replaced by the [Nexus Capability Operator](../../operational/kubernetes-operator/index.md).
- **Webex Contact Center integration recipes** (`webex-integration.md`, `webex-implementation-questions.md`, `call-recording-pseudocode.md`) -- replaced by the platform's generic FDW / ETL / CDC connector framework. Webex CC remains a supported source system, just not a hard-coded special case.
- **Call processing pipeline** (`call-processing-algorithm.md`, `developer-guide.md`, `sfdcaction.md`) -- the platform's generic Journeys runtime supersedes this.
- **WXCC simulator** -- replaced by the per-Solution simulator pattern. The SFDC simulator survives for CRM / Salesforce-backed Solutions.
- **Toolkit Executive Summary**, **Toolkit Deployer PRD** (functional design + requirement docs), **Toolkit AWS WAFR Compliance**, **Toolkit-flavoured Capability Architecture** -- replaced by the new [Business](../../business/index.md), [Functional Specifications](../../functional/index.md), [Features & Capabilities](../../features/index.md), and [Technical](../../technical/index.md) sections.
- **CallSense v0.0.1 release notes** and **CallSense v0.0.1 test plan** -- this v0.1.0 release replaces them.
- **62 legacy files** in total deleted in the cleanup pass.
