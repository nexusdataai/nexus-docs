## Product Relationship

### How NexusAI and Toolkit Work Together:

```
1. Customer identifies need for enterprise AI operationalization
   -> Reviews NexusAI Executive Summary
   -> Sees 40-60% workflow automation potential
   
2. Customer subscribes to NexusAI enterprise support
   -> Receives Toolkit access (included)
   
3. Customer uses Toolkit to deploy NexusAI
   -> 30-minute full-stack provisioning
   -> Cloud or on-premise Kubernetes
   
4. Customer uses NexusAI to operationalize AI
   -> Connects enterprise systems, builds knowledge graphs
   -> Deploys autonomous agents across workflows
   -> Achieves measurable operational impact
   
5. Customer uses Toolkit for lifecycle management
   -> Apply updates and patches
   -> Scale infrastructure
   -> Deploy to additional environments
```

**Key Insight:** Toolkit enables NexusAI adoption by eliminating deployment friction.
