## Product Relationship

### How CallSense and Toolkit Work Together:

```
1. Customer identifies need for call analytics
   → Reviews CallSense Executive Summary
   → Sees 25-55x ROI potential
   
2. Customer purchases CallSense license
   → Receives Toolkit access (included)
   
3. Customer uses Toolkit to deploy CallSense
   → 30-minute infrastructure provisioning
   → Complete AWS stack deployed
   
4. Customer uses CallSense for call analytics
   → Processes calls, generates insights
   → Improves conversion rates
   → Achieves 25-55x ROI
   
5. Customer uses Toolkit for lifecycle
   → Apply updates and patches
   → Scale infrastructure
   → Deploy to additional environments
```

**Key Insight:** Toolkit enables CallSense adoption by eliminating deployment friction.
