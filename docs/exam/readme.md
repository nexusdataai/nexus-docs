Earnable Proficiencies
Stars	Proficiency	Description
Feature-level
Able to reason about bounded feature changes. Identifies obvious constraints and proposes feasible solutions. May struggle with platform-level thinking or provide shallow answers for external boundary decisions.
Technical Team Lead
Team-pattern
Able to reason about system-internal patterns that others would follow. Shows clear trade-off analysis and awareness of operational concerns. Meaningful attempt at platform thinking with some gaps.
Platform-boundary
Able to reason about external-facing decisions where other teams or customers depend on the design. Deep thinking about API contracts, versioning, backward compatibility, security isolation, and developer experience.
