## Root Cause Analysis

### Why All Pages Show 404

MkDocs is a static site generator that:
1. Only processes files within the `docs/` directory
2. Cannot serve files from parent directories (`../`)
3. Cannot follow symlinks outside the docs root (by default)
4. Builds a static site with only files it can access

**Current Structure**:
```
/opt/mycode/trilogy/
├── nexus-docs/
│   └── docs/              ← MkDocs root (can only serve from here)
│       └── index.md
├── nexus-deployer/
│   └── doc/               ← Files here CANNOT be served
│       └── business/
├── nexus-backend/
│   └── doc/               ← Files here CANNOT be served
```

**The Plan vs Reality**:
- **Plan**: Link to docs in original locations (avoid duplication)
- **Reality**: MkDocs cannot serve files outside `docs/` directory
- **Result**: All external links = 404 errors

---

## Solutions

### Option 1: Copy Files into docs/ (Recommended)
Copy all referenced files into the `docs/` directory structure.

**Pros**: 
- Simple, works immediately
- Full MkDocs feature support
- Proper navigation and search

**Cons**: 
- File duplication
- Need sync mechanism for updates

### Option 2: Symbolic Links
Create symlinks inside `docs/` pointing to external files.

**Pros**: 
- No duplication
- Files stay in original location

**Cons**: 
- Requires `follow_symlinks: true` in mkdocs.yml
- May not work on all platforms
- GitHub Pages may not support

### Option 3: Monorepo with Docs Aggregation
Restructure to have all docs in one location.

**Pros**: 
- Clean structure
- No duplication

**Cons**: 
- Major restructuring required
- Changes repository organization
